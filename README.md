# 🍽️ Dar Zayna — Moroccan Restaurant Website

A modern and elegant restaurant website designed for **Dar Zayna**, inspired by Moroccan culture and traditional hospitality.

The project focuses on creating a premium digital experience while keeping the interface simple, responsive, and easy to use.

## ✨ Features

- 🏠 Elegant restaurant landing page
- 🍽️ Interactive menu with categories
- 📅 Reservation form displayed in an elegant popup
- 🛒 Order interaction
- 🖼️ Restaurant gallery
- ⭐ Customer reviews section
- ❓ FAQ section
- 📱 Fully responsive design
- ✨ Smooth animations and scroll effects
- 📱 Mobile navigation
- 🎨 Moroccan-inspired visual identity

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
